# Selina Love Website

A responsive romantic website inspired by the supplied design. Includes a love note, relationship timer, gallery placeholders, and a working local audio player.

## Run locally
Open `index.html` in a browser. Keep the `assets` folder next to it.

## Publish
Upload the contents of this folder to a public GitHub repository and enable GitHub Pages, or deploy this folder as a static site on Render. The published site must include `index.html` and the `assets/` folder.

## Personalize
- Edit the message and reasons in `index.html`.
- Use the “Set our start date” button to set the relationship start date.
- Replace `assets/selina-hero.jpg` with your preferred image.
- Replace `assets/our-song.mp3` with your own audio file if desired.
